# Image Limitations (Prototype)

The prototype uses the supplied images at their current sizes. Some of them will look soft on high-density (retina) screens. No further images are planned for this prototype.

## Hero image

- File: `images/hero.png`
- Current size: 1417 x 794 px
- Size that would be sharp at high density: about 2938 px wide at the current desktop size
- On screen: the hero fills the top of the page, so the softness is visible on retina screens.
